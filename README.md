# form-validation

Simple registration form with real-time validation built using HTML, Tailwind CSS and JavaScript.

## Features
- Name, Email (Gmail only), Password fields
- Real-time red/green border feedback as you type
- Error messages shown below each invalid field
- Submit validates all fields before alerting success

## Validation Rules

| Field    | Rule                          |
|----------|-------------------------------|
| Name     | Cannot be empty               |
| Email    | Must be a Gmail address       |
| Password | Minimum 6 characters          |

## Tech Stack
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript

## Run
Open `index.html` directly in your browser. No setup needed.
